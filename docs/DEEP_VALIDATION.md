# 持续格式与交互验证

## 有种子的属性测试

`pnpm test:fuzz` 使用fast-check在真实引擎边界生成输入：任意有界JSON、有效模板/数据往返、特殊参数名、异常几何、媒体字节、随机/变异ZIP、真实XLSX往返和HTML/Word兼容序列化中的文字隔离。固定用例同时覆盖循环/深度、复杂内容只读、真实零/空值和前导零。它执行的是安全预算内的输入探索，不以耗尽系统内存作为通过条件。

普通 `pnpm verify` 自动运行这些测试；默认每条属性250次，真实ZIP和XLSX案例分别限制100/20次。`.github/workflows/deep-validation.yml` 提供每日和手动运行，普通属性每次3000次，二进制实物案例仍保留明确上限。日志保留种子、失败路径和缩小后的反例，失败直接阻断，不重试掩盖问题。

```sh
pnpm test:fuzz
MR_FUZZ_RUNS=3000 MR_FUZZ_SEED=123456 pnpm test:fuzz
# 用失败日志中的seed/path，仅重跑对应属性：
MR_FUZZ_SEED=123456 MR_FUZZ_PATH='0:1' pnpm test:fuzz -t '属性名称'
```

种子/次数参数非法时直接拒绝。新反例应先复现，再保存稳定回归；不要通过过滤真实输入、更新快照或增加重试使失败消失。本轮属性测试发现并修复了BigInt异常几何生成错误文案时的原生TypeError；循环/深层组件也在递归绘制前结构化拒绝。

这覆盖当前插件提供的输入接口，不声称已覆盖所有Excel扩展格式、PDF阅读器、编码库内部或任意恶意文件；ZIP/像素/深度预算、严格输出和隔离执行共同兜底。

## 真实浏览器可访问性

`pnpm test:a11y` 在真实Chromium中使用axe检查WCAG 2/2.1/2.2 A/AA相关自动规则，覆盖预览、搜索、目录、设置、设计器分区及远程参数的选项/错误状态。报告保留完整节点、规则、未能自动判断的 `incomplete` 项。已有键盘、IME、模态焦点与返回定位继续独立回归；未关闭颜色对比度规则或整体排除产品区域。

参考[Playwright官方无障碍指南](https://playwright.dev/docs/accessibility-testing)。自动检查不能证明完整无障碍合规，辅助技术实际播报须按[外部验收](./EXTERNAL_ACCEPTANCE.md)执行。

完整浏览器验收使用单一Playwright调度器；不要让多个独立命令共享同一组示例服务，避免其中一个结束时关闭另一组仍在使用的服务。CI自动要求独占；本地可用 `MR_E2E_OWN_SERVERS=1 pnpm test:e2e --workers=2 --retries=0` 要求本次运行拥有服务生命周期，端口已被占用时直接失败。日常开发未设置该项时仍可复用已有示例服务。

## 文件与设备验收

`pnpm check:acceptance` 生成并回读代表样例，包内附SHA-256清单、合成数据和人工结果表。真实Office、打印机、扫码枪与屏幕阅读器需要对应环境，结果未执行就保持 `not-run`，不会被自动门禁改为通过。
