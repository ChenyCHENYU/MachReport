# 质量与还原说明

MachReport 的质量结论以代码门禁、真实文件回读和浏览器几何回归为依据。通过测试不等于所有宿主、字体和复杂模板都已经验收，也不代表工程已经没有优化空间。

## 2.26.1 设计预览配置稳定性

项目接入复验发现，Vue 3.2.47 宿主的标签工作台会在首次挂载时反复渲染。父级控制器读取预览状态，而内联刷新配置在每次父级渲染时重建，形成响应反馈；40 条合成记录并不是无界业务输入。相同项目源码下，2.22.0 正常，2.26.0 出现内存异常；仅移除临时副本中的该刷新属性即可恢复完整标签操作，确认了问题边界。

设计器与标签工作台现在共用按模板身份维护的刷新策略，同一模板编辑、工具状态和设计/预览切换不再创建新策略；更换模板身份仍会更新策略并清理旧视图。保留旧快照、草稿和撤销语义继续生效，宿主无需增加参数。回归测试实际挂载标签组件，反复改变控制器输出状态并核对策略零次重发，同时验证两个组件的消费及模板身份切换。旧实现会产生六次多余更新，新实现保持稳定。

实际画布回归还发现，异步“草稿已暂存”曾使画布纵坐标200→224.5px，影响鼠标命中与拖动几何。正常后台暂存现与既有头部状态共用位置，恢复、暂存错误和冲突操作仍保留原区域。浏览器同时核对真实命中、非零拖动、DOM与模板持久几何，以及一次撤销后的完整恢复；不再允许两个组件都未移动时用“相同位移”断言误判通过。

最低 Vue 的严格声明、SSR 和文件输出消费不能替代交互验收。本轮另用 Vue 3.2.47 的隔离宿主页验证材料标识的真实打开、设计、预览和会话连续性；该宿主页使用合成数据，不能作为线上业务实绩或实体打印设备的验收证据。

2026-11-12 完整 `verify` 通过301个文件、2599项测试；语句88.37%、分支82.78%、函数88.09%、行93.04%。沿用本机发布的2个Vitest工作进程，5秒超时、性能预算和零重试保持不变。另将虚拟时钟下的协作分片测试改为主动推进时钟，强制让出时间片后仍可验证150ms预览合并，不再依赖机器快慢。

## 宿主样式隔离

渲染器只重置自己创建的节点，不向宿主注入通用 `table / td / div / img` 规则。单元格位置和跨度来自 `resolveGridLayout`，内容不再参与原生表格的最小尺寸重排；行高、内距、字号、行距与边框按计划处理。

真实Chromium回归注入了大padding、32px字号、3倍行高、强边框、全局文字/图片/变换等普通宿主规则，比较注入前后以及HTML打印回读后的几何和样式。旧版6.5mm行被撑至134px，修复后24.5625px，与计划24.567px相符。另覆盖rowSpan、独立边框、空文本行和图片尺寸。

宿主强制 `!important`、针对插件的伪元素和字体环境变化仍需集成验收；样式隔离不使用Shadow DOM，宿主仍能通过已声明主题和模板样式定制。不要将普通样式污染已修复表述为任意CSS都无法影响渲染。

## 输出完整性与媒体护栏

`fidelity: "strict"` 在静态能力预检和实际 PDF 编码完成后均执行门禁。缺字、坏图片、组件渲染失败、缺失粗斜字面和文字溢出会阻止文件交付。`warn` 保留可检查结果，动态问题进入 `diagnostics`，不能把收到 bytes 等同于内容完整。`unsupported-text`、`invalid-image-data`、`component-render-failed`、`output-degraded` 带页/组件位置；图片预算超限始终失败。

PDF、普通 Excel、Excel 图片导入和资产准备共用 PNG/JPEG 签名与头部尺寸检查，MIME 大小写及 jpg/jpeg 统一处理。默认单图16 MiB、唯一媒体合计32 MiB、1000个媒体、单图1600万像素、合计6400万像素、单边16384像素；这些上限在进入像素解码器前检查，重复Logo只计一次。媒体预算包含已有 `imageData`，适配器自身的 `assetBudget` 另控制生成数量、时间和产出大小。

连续 Excel 在工作表内部按4096个处理单位或8ms检查协作让出，取消不再等整张Sheet写完；压缩期硬终止由[自动隔离编码](./guides/automatic-export.md)执行，浏览器需提供构建器管理的Worker工厂，Node可直接使用包内线程入口。本地回退会明确报告不能硬取消。Node逐行Excel的 `onProgress` 是观察器，抛错或Promise拒绝不会反转已经完成的文件写出；业务中止用 `signal`。

PNG/JPEG原生drawing可从Excel导入，保留选区内位置与尺寸，并通过overlay锚点回写Excel而不挤动数据行。跨预览段、未完整包含的图片、图表对象、裁剪/旋转/外部链接均不宣称完全还原。混合字体格保留为只读richParagraphs与text/value回退；Canvas/PDF可绘制格内内容，XLSX只对其原生可表达部分承诺保留，不能把任意自由页面坐标转换为像素一致工作表。
