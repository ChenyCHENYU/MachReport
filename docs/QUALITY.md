# 质量与还原说明

MachReport 的质量结论以代码门禁、真实文件回读和浏览器几何回归为依据。通过测试不等于所有宿主、字体和复杂模板都已经验收，也不代表工程已经没有优化空间。

## 代码质量门禁

`pnpm verify` 包含类型、零警告 ESLint、复杂度、全部工作区构建、单测覆盖率、文档及真实 npm 包隔离消费；Chromium 另跑 `pnpm test:e2e --retries=0`。Vitest 和 Playwright 默认也都是零重试。

`pnpm check:quality` 使用 ESLint 自身的 classic complexity 规则，检查全部生产 TypeScript / Vue 函数，**上限20，无存量文件豁免**；测试夹具不参与复杂度统计。`pnpm lint` 同时执行同一门禁，避免只输出报告而未阻断回归。

本轮主要热点按业务职责拆分，保留公开接入方式：

| 位置 | 2.3.0基线 | 本轮 |
| --- | --- | --- |
| `createTableTemplate` | 74 | 16；分离布局、尺寸、标题、列校验和宽度分配 |
| `paginateTemplate` | 60 | 13；分离组装、行测量、分组、汇总与换页 |
| PDF主入口 | 31 | 9；字体、文本、网格、图形和页面各自处理，文件内最大11 |

数字只衡量分支规模。闭包型生命周期编排仍应保持可理解的关联，不为缩短行数机械拆散状态。依赖边界、类型契约、取消、模板安全校验和既有性能预算同时保留。

## 宿主样式隔离

渲染器只重置自己创建的节点，不向宿主注入通用 `table / td / div / img` 规则。单元格位置和跨度来自 `resolveGridLayout`，内容不再参与原生表格的最小尺寸重排；行高、内距、字号、行距与边框按计划处理。

真实Chromium回归注入了大padding、32px字号、3倍行高、强边框、全局文字/图片/变换等普通宿主规则，比较注入前后以及HTML打印回读后的几何和样式。旧版6.5mm行被撑至134px，修复后24.5625px，与计划24.567px相符。另覆盖rowSpan、独立边框、空文本行和图片尺寸。

宿主强制 `!important`、针对插件的伪元素和字体环境变化仍需集成验收；样式隔离不使用Shadow DOM，宿主仍能通过已声明主题和模板样式定制。不要将普通样式污染已修复表述为任意CSS都无法影响渲染。

## 输出支持矩阵

| 内容 | DOM / 浏览器打印 | Canvas / PNG | PDF | XLSX |
| --- | --- | --- | --- | --- |
| 列宽、行高、合并格 | 共享几何 | 共享几何 | 共享几何 | 工作表列宽 / 行高 / 合并 |
| 字号、基础颜色、对齐、行距 | 支持 | 文本与网格支持 | 支持，缺字阻止静默成功 | 支持常规工作表样式 |
| 列表内距与字号单位覆盖 | 使用同一计划与样式合并 | 同左 | 同左 | 字号继承统一，非毫米坐标复刻 |
| 粗体、斜体、下划线 | 按浏览器字体能力 | 部分文字装饰未完整绘制 | 内置Helvetica字面支持；单个自定义字面限制会告警 | 支持 |
| 富文本 | 浏览器内联样式 | 仍有纯文本降级 | 纯文本并返回保真告警 | 有文本回退时保留文本并告警，否则跳过告警 |
| 图片、二维码等图片型组件 | 按图片数据渲染 | 当前未绘制 | PNG / JPEG data URI，其他情况告警 | 当前跳过并告警 |
| 旋转、透明度、两端对齐等 | 按具体浏览器样式 | 非完整支持 | 未支持项明确告警 | 不支持自由页面坐标复刻 |

PDF使用单个自定义字体文件时无法据此生成其他粗斜字面；字体族和字形覆盖需与实际业务数据匹配。固定纸张中的超高单行仍需合理行高与内容安排；分页和PDF分别返回诊断，不应忽略告警后宣称文件完全还原。

Word出口是兼容HTML的 `.doc`，不是 `.docx`；浏览器HTML打印回读已验证，实际Microsoft Word排版仍需单独验收。主流宽表预览与连续Excel不受A3/A4固定纸宽约束，文件格式和阅读器自身限制仍按[Excel指南](./EXCEL.md)、[PDF指南](./PDF.md)处理。
