# 字体宽度模型校准数据

> 测量环境：Chromium headless（Playwright）· Microsoft YaHei · 100px 基准
> 测量脚本见 git 历史 `font-probe.cjs`（一次性工具，已删除）

## 实测 vs 模型（校准前 → 校准后）

| 字符组 | 实测 avg(em) | 旧模型 | 新模型 |
|---|---|---|---|
| 数字 0-9 | 0.586 | 0.55 | **0.59** |
| 小写字母 | 0.538 | 0.55 | **0.54** |
| 大写字母 | 0.667 | 0.55 | **0.67** |
| CJK 汉字 | 1.000 | 1.00 | 1.00 |
| 标点 .,:;' | 0.244 | 0.32 | **0.26** |
| 宽字符 mwMW@ | 0.950 | 0.85 | **0.95** |
| 空格 | 0.296 | 0.28 | **0.30** |

## 局限

- 窄字符组（il jtf 等）实测 min 0.27~0.29，模型归并为 0.26，折行略保守（多折早于真实）——可接受方向：宁可早折不溢出
- bold 系数 1.04 为经验值（YaHei bold 略宽）
- 其他字体（宋体/黑体/Calibri）待后续校准；CJK 全宽在等宽中日字体下稳定
