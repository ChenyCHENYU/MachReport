# 本轮产品增强与后续验收

## 2.17 产品增强范围

| 对照建议 | 本轮实现 | 保留的明确边界 |
| --- | --- | --- |
| 复杂报表深度 | 可选层级矩阵、逐级排序/小计、稳定维度身份；独立flow区域组合 | 不把同一数据区域的树/主从/矩阵互斥直接解除 |
| 大宽表性能 | 页窗口内的行列视口裁剪、合并锚点、键盘定位、DOM复用 | 搜索/冻结模式及旋转网格使用完整页或网格；打印和输出不裁剪 |
| 编辑计算 | 自有会话workspace，按行依赖复用，单次分页有界测量缓存 | 分组/整表/字符串公式保守重算；分页仍按完整内核，不宣称完全局部重排 |
| 组件扩展 | 受控注册器、同kind多扩展、懒加载/释放、现有assets跨端一致、设计器原生事务插入 | 标准组件和资源模型；不执行模板脚本，不新增任意第三方DSL |
| 数据语义与交互 | 契约共享格式/聚合/计算说明，可定位解释；层级设计器沿用当前属性与预览 | 指标口径、权限和真实数据由宿主负责，不擅自补数据或计算规则 |
| 后端通用 | OpenAPI 3.1、Java标准库客户端、按页文档窗口、内存/单进程文件适配 | 多实例/租户授权由宿主保证，分批输出不代表输入和聚合无界 |
| 长期兼容 | 显式模板迁移链、API增删/签名差异回执、实际旧入口和模板回归 | 不删除既有导出，不自动接受破坏性签名差异 |

复用现有内核和依赖，新增能力按需使用；不引入竞品源码。完整命令、结果与本机测量以[质量说明](./QUALITY.md)和本轮回执为准，不以测试数量代替真实兼容范围。

## 仍需外部环境的验收

用户已确认没有Office/打印/扫码实机环境。验收包与软件回读继续提供，真实Office、打印设备、扫码设备及屏幕阅读器人工验收保持未执行，按[外部验收](./EXTERNAL_ACCEPTANCE.md)记录具体版本、误差与证据。
